System Architecture

Come Funziona il Concetto di Gerarchia

Il plugin supporta due pattern architetturali per gestire strutture gerarchiche complesse.

1. Multi-Dimension Level Grouping

Ideale per dati categorici dove ogni riga rappresenta un record con granularità a più livelli (es. Region > Country > City > Store).

  • Query SQL con GROUP BY sequenziale
  • Costruzione albero via `buildMultiDimensionTree`
  • Subtotali automatici per ogni livello intermedio

2. Parent-Child Adjacency Graph

Ideale per strutture ricorsive ad albero con profondità variabile (es. Organigrammi employee_id → manager_id o Piani dei Conti P&L).

  • Risoluzione grafi di adiacenza con rilevamento cicli
  • Calcolo profondità depth e percorsi path
  • Query SQL Recursive CTE per database compatibili
Installation & Deployment

Installazione Rapida in 1 Comando

Installa e registra automaticamente il plugin sulla tua istanza locale di Apache Superset 6.1.0.

# Install directly into local Superset 6.1.0 on Windows PowerShell
.\scripts\install.ps1 -SupersetPath "C:\path\to\superset"
