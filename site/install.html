Installation & Deployment

Installazione Rapida in 1 Comando

Installa e registra automaticamente il plugin StratumTree sulla tua istanza locale o containerizzata di Apache Superset 6.1.0. 

# Install directly into local Superset 6.1.0 on Windows PowerShell
.\scripts\install.ps1 -SupersetPath "C:\path\to\superset"
🪟 1. Windows Native

Lo script install.ps1 esegue il build dei pacchetti monorepo, inietta la configurazione nel registry MainPreset.js ed esegue il rebuild del bundle webpack.

🐳 2. Docker Environment

Utilizza docker-compose.override.yml per montare la cartella dei plugin all'interno del container superset-node, senza dover ricostruire le immagini base.

🛡️ 3. Safe AST Ingestion

L'installer basato su Python AST analizza e inietta le dipendenze in modo non distruttivo, con supporto rollback automatico in caso di errore.
